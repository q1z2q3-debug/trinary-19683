## FAQ

### Q1 · What is TNE-Core / 三元九维19683?
A deterministic symbolic cognition layer built from 9 dimensions (lines) × 3 states each (D carry / R judge / T gain) = **3⁹ = 19,683** states, giving LLMs and agents a recomputable, auditable thinking skeleton. It is deterministic, not divinatory.

### Q2 · What is its relation to the I-Ching / fortune-telling?
None in function. It borrows the symbolic shell of "gua / line / yin-yang-transition", but the interior is deterministic algorithms: every gua (9-line sequence) maps to a unique, recomputable structural signature and rank; inference, perturbation and migration are all replayable, auditable and reversible. It does not provide fate prediction or auspicious/inauspicious claims.

### Q3 · Is it science or mysticism? What is the verifiability?
It is a formal/engineering system aimed at verifiability: ① full parse of 19,683 gua with 3-generation correction, 100% line–text consistency; ② self-adaptive rank uniquely determined by 5-dim structural signatures, 19,661/19,661 leave-one-out consistent (100%); ③ falsification dynamics (Cognition Board v2) allow a pattern to be overturned by counter-examples and to migrate — testable; ④ a consistency validator and open APIs allow independent reproduction. It is a formal engineering of "trinary thinking", not mysticism.

### Q4 · What can it do (use cases)?
As a symbolic cognition layer for LLMs/agents: ① deterministic coordinates for free association and decisions (locatable); ② a refuter for hallucination hedging (knowing it is wrong and where to go); ③ jump→migration that freezes validated associations into recomputable rules (learning rather than mere inference); ④ multi-agent sharing of auditable reasoning chains; ⑤ already applied to financial state cognition research (sideways-breakout / refutation risk-control / multi-factor consensus with experience-adaptive parameters). Ships 15+ APIs, a single-file offline HTML model, and a Python package.

### Q5 · How to install / use?
Fastest: open the single-file offline HTML model in a browser. Local service: `python3 server.py` → http://127.0.0.1:8000/. CLI: `python3 engine.py`. Package: PyPI `trinary19683` (Apache-2.0). Data: GitHub / HuggingFace (see `scripts/download_data.py`).

### Q6 · How is it different from ordinary LLMs / vector embeddings?
Vector embeddings are continuous, non-locatable and hard to audit; TNE-Core is a discrete, locatable, recomputable, auditable deterministic symbolic space. They are complementary: vectors handle semantics, the symbolic layer provides the "skeleton/coordinate/ruler". TNE-Core does not replace LLMs; it adds a verifiable structural layer to their reasoning.

### Q7 · Data source and quality?
Built on a full parse of 729 source files → 19,683 gua, corrected over 3 generations: ~8,578/19,683 gua already matched the canonical layer table; the other 11,105 were re-keyed to the trinary canonical table and their text rebuilt from the corpus to guarantee line–text consistency. The knowledge base ships canonical JSON, SQLite, index, layer table, rank-signature table and a data-quality report.
